Dự án được xây dựng theo mô hình đa module (Multi-module), tách biệt giữa ứng dụng
người dùng và lõi công nghệ quét mống mắt.

--------------------------------------------------------------------------------
1. TẦNG GỐC (ROOT PROJECT)
--------------------------------------------------------------------------------
Nơi quản lý cấu hình tổng thể và các tài nguyên dùng chung.

*   build.gradle (Project): Cấu hình tổng cho toàn bộ dự án, định nghĩa các kho
    tải thư viện (Google, Maven) và phiên bản công cụ build.
*   settings.gradle: "Mục lục" của dự án, khai báo các module thành phần:
    ':app' và ':iris'.
*   gradle.properties: Chứa các thiết lập hệ thống cho bộ máy Gradle (cấp phát RAM).
*   local.properties: Lưu đường dẫn đến Android SDK trên máy tính cá nhân.
*   irissample.json: File cấu hình metadata hoặc License cho thiết bị IriTech.
*   gradlew / gradlew.bat: Script để chạy lệnh Gradle mà không cần cài đặt sẵn.
*   sample_..._import.csv: Các file dữ liệu mẫu để kiểm tra tính năng nhập liệu
    hàng loạt (Sinh viên, Admin, Môn học).
*   iricapture+: Thư mục chứa tài liệu hướng dẫn phần cứng và cấu hình thiết bị
    quét mống mắt IriAegis.

--------------------------------------------------------------------------------
2. MODULE ỨNG DỤNG CHÍNH (app)
--------------------------------------------------------------------------------
Chứa giao diện người dùng (UI) và logic quản lý nghiệp vụ.

*   src/main/java/com/iritech/irissample/:
    - Activity/: Các màn hình như LoginActivity, RegisterAdminActivity, StudentListActivity.
    - DatabaseHelper.java: Quản lý cơ sở dữ liệu SQLite (Lưu trữ thông tin).
    - ImportCsvActivity.java: Xử lý việc đọc và nạp dữ liệu từ các file .csv.
    - EncryptionHelper.java: Mã hóa bảo mật dữ liệu mống mắt.
    - EmailService.java: Tự động gửi email thông báo.
*   src/main/res/ (Resources):
    - layout/: Giao diện màn hình dọc (XML).
    - layout-land/: Giao diện tối ưu khi xoay ngang điện thoại.
    - drawable/: Icon, nút bấm, hình ảnh đồ họa của ứng dụng.
    - values/: strings.xml (ngôn ngữ), colors.xml (màu sắc), themes.xml (phong cách).
    - mipmap/: Chứa icon ứng dụng với nhiều độ phân giải khác nhau.
*   src/main/jniLibs/: Chứa các file .so (C++). Đây là các thư viện mã máy xử lý
    thuật toán mống mắt cực nhanh cho từng loại chip (arm64, armeabi...).
*   src/main/assets/: Chứa các file tĩnh, template hoặc font chữ đi kèm app.
*   AndroidManifest.xml: Khai báo quyền truy cập (Camera, USB, Storage) và danh
    sách màn hình.

--------------------------------------------------------------------------------
3. MODULE THƯ VIỆN CÔNG NGHỆ (iris)
--------------------------------------------------------------------------------
Đây là "linh hồn" của dự án, chứa mã nguồn điều khiển thiết bị quét mống mắt.

*   src/main/java/com/iritech/iris/:
    - IriController.java: Điều khiển khởi động, chụp và phân tích mống mắt.
    - CaptureActivity/Fragment: Giao diện khung soi mắt (vòng tròn hướng dẫn).
    - CustomIrisCamera.java: Tùy biến camera để chụp tia hồng ngoại.
*   src/main/res/:
    - drawable/: Chứa ic_circle, ic_stop... các icon chỉ dẫn trạng thái quét.
    - anim/: Các hiệu ứng xoay, nhấp nháy (rotate_full.xml) khi đang quét.
    - values/attrs.xml: Định nghĩa các thuộc tính để app có thể tùy chỉnh màu
      sắc, kích thước vòng tròn quét từ bên ngoài.
*   build.gradle (Module: iris): Khai báo đây là một thư viện Android tái sử dụng.

--------------------------------------------------------------------------------
4. MỐI QUAN HỆ VÀ LUỒNG DỮ LIỆU
--------------------------------------------------------------------------------
1. Build: Gradle đọc cấu hình gốc -> Build thư viện 'iris' -> Nhúng vào 'app'.
2. Khởi chạy: App mở màn hình Login/Register -> Gọi module 'iris' để mở camera.
3. Xử lý: Thư viện C++ (jniLibs) tính toán -> Trả về mã mống mắt cho 'app'.
4. Lưu trữ: App dùng DatabaseHelper để lưu vào máy hoặc gửi Email báo cáo.

Dự án được phân tách rõ ràng giúp việc bảo trì và nâng cấp công nghệ quét mống
mắt không làm ảnh hưởng đến giao diện ứng dụng chính.
